# 月账通｜智能账单复盘助手

一个从真实个人消费复盘需求出发设计的本地账单分析工具。它将不同来源的流水统一为同一套数据结构，完成消费分类、疑似重复识别、朋友返还关联与月度复盘，帮助用户回答三个问题：

1. 这个月流水里一共支出了多少？
2. 扣除朋友返还后，我实际承担了多少？
3. 哪些类别和异常支出最值得复盘？

> 项目定位：Personal Data Product / AI-assisted Product Project  
> 项目角色：需求洞察、产品设计、数据规则设计、AI 协作开发、结果验证

## 核心案例：流水金额不等于个人实际消费

```text
聚餐支付          -¥300
朋友返还          +¥200
────────────────────
流水显示支出       ¥300
个人实际承担       ¥100
```

系统结合时间、金额、交易对象与备注寻找可能相关的收支记录。匹配结果会标记为“疑似关联”，保留人工复核入口，不直接覆盖原始流水。

## 核心功能

- CSV / TXT 账单导入与字段统一
- 微信、支付宝、银行卡等来源字段映射
- 基于商户与交易说明的消费分类
- 支付平台与银行卡重复流水识别
- 朋友返还、AA 收款等关联流水识别
- 流水总支出与个人实际承担金额双口径展示
- 分类结构、高额支出与月度复盘提示
- 交易明细筛选、人工调整与 CSV 导出
- 浏览器本地解析，账单不上传服务器

## 如何体验

### 在线体验

项目为纯静态网页，可通过 GitHub Pages 运行。部署完成后访问：

`https://cutekaka.github.io/bill-review-assistant/`

进入页面后点击“载入演示数据”，无需上传任何文件即可体验完整流程。

直接下载仓库并用浏览器打开 `index.html`。如浏览器限制本地文件读取，可在项目目录启动任意静态服务器。

```bash
python -m http.server 8000
```

随后访问 `http://localhost:8000`。

### 演示数据

`demo-data/sample_bill.csv` 中的数据全部为虚构内容，包含：

- 多平台日常消费
- 同笔交易在支付平台与银行卡的疑似重复记录
- 聚餐垫付 300 元与朋友返还 200 元
- 分类统计与高额消费示例

## 数据口径

| 指标 | 含义 |
|---|---|
| 流水总支出 | 排除已识别重复项后的支出流水合计 |
| 关联返还 | 与垫付消费疑似相关的朋友返还、AA 收款 |
| 个人实际承担 | 流水总支出减去已关联返还 |
| 月度结余 | 收入减去流水总支出 |
| 疑似重复 | 金额接近、时间相近且描述存在平台支付特征的跨来源记录 |

所有关联与重复识别均为辅助判断，复杂场景仍需用户核对。

## AI 协作方式

AI 主要用于代码生成、调试与规则实现；项目中的问题定义、数据口径、分类标准、异常识别和结果验证由我完成。开发过程遵循：

```text
真实账单测试 → 发现误判 → 定位规则问题 → 调整需求 → 再次验证
```

重点不在一次性生成网页，而在把生活语义转化为可执行规则，并持续检查机器输出是否符合真实消费逻辑。

## 版本演进

- **V1｜多平台合并**：导入、字段统一与基础收支统计
- **V2｜分类与可视化**：消费分类、结构分析与交易明细
- **V3｜复盘能力**：月度比较、高额支出与提示
- **V4｜真实消费口径**：朋友返还与个人实际承担金额
- **V5｜规则复核**：调整易误判类别，保留不确定性提示

## 隐私说明

- 页面不包含真实账单、真实姓名、支付账号或银行卡号
- 导入文件仅在当前浏览器中解析
- 项目不包含后端、数据库、Cookie 或用户追踪脚本
- 请勿将个人真实账单提交到公开仓库

## 技术说明

该项目使用原生 HTML、CSS 与 JavaScript 实现，无需构建工具或后端服务。当前作品集版本正式支持 CSV / TXT；Excel 与 PDF 解析属于后续扩展方向。
